Sistema operativo:
Es el software principal del computador. Administra los recursos del sistema y permite ejecutar aplicaciones y servicios.

Node.js:
Es un entorno de ejecución para JavaScript. Permite crear y ejecutar servidores fuera del navegador.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y las respuestas que reciben los usuarios.

Puerto:
Es un punto de comunicación utilizado por el servidor. En esta práctica se utiliza el puerto 3000 para recibir solicitudes.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a monitorear el funcionamiento y detectar errores.
