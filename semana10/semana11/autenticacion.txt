El login permite identificar a un usuario antes de darle acceso a las funciones de una aplicación. La autenticación garantiza que solo las personas autorizadas puedan acceder a determinadas rutas o realizar acciones específicas. Algunas rutas deben estar protegidas porque contienen información privada o administrativa. No deben exponerse públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles. Esto contribuye a proteger la privacidad y la seguridad de los usuarios.
